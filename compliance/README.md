# ScopeKeep governance documents

These documents are engineering control mappings and product-design aids. They are **not certifications, legal opinions, audit reports, or guarantees of compliance**.

The current release supports a local-first deployment posture, project isolation, opt-in transcript capture, secret redaction, signed retrieval evidence, complete workspace export, and verified workspace deletion. Whether a customer complies with the GDPR, EU AI Act, SOC 2, HIPAA, or another framework depends on the actual deployment, intended purpose, data, contracts, policies, people, and controls outside ScopeKeep.

Treat the detailed documents in this directory as mapping drafts, not certifications or legal opinions. Validate every control against the current code and customer environment before using it in procurement or assurance work.
